`$ARGUMENTS` 작업을 처리한다. 메인 세션에서 직접 한다(서브에이전트 없음).

1. **파악**: 관련 기획 노트와 코드를 필요한 부분만 읽는다.
2. **계획**: 바꿀 파일 목록, 새 클래스의 목적·관계(합성/집약)·근거, 모르는 점을 짧게 제시하고 승인을 받는다.
3. **구현**: 승인된 범위만 수정한다. 범위 밖 문제는 "후속 작업"으로 적기만 한다.
4. **검증**: 컴파일을 확인한다(UnityMCP `read_console`, 안 되면 Roslyn). 가능하면 Play 모드에서 확인한다.
5. **보고**: 변경 파일, Unity에서 사용자가 할 일(메뉴 실행 등), 미검증 항목.
