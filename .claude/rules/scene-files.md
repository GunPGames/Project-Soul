# 씬·프리팹·메타 파일 규칙

- 이 파일들은 Unity가 관리하는 YAML이다. 직접 텍스트 편집하지 말고 UnityMCP나 에디터 스크립트로 바꾼다.
- 부득이 직접 고칠 때는 GUID·fileID를 절대 바꾸지 않고, 변경 전후를 사용자에게 보여 준다.
- `.meta`를 지우거나 다시 만들지 않는다. 참조가 끊긴다.
- `Assets/ThirdParty` 아래 파일은 비공개 서브모듈이다. 바꿨다면 서브모듈 쪽 커밋이 먼저다.
